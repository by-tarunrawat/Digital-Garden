# Cognitive Load in UI

Interfaces fail when working memory demands outpace human processing limits.

### Key Principles
- **Hick's Law:** Decision time scales logarithmically with the number of options presented.
- **Miller's Law:** Working memory holds approximately $7 \pm 2$ chunks of information at once.

### Practical Rule
Progressive disclosure: hide secondary actions until the primary action is resolved.
